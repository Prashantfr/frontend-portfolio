# Frontend Development Portfolio 🚀

A collection of my frontend development practice, projects, and implementations using **HTML, CSS, JavaScript, React.js, and TypeScript**.

This repository documents my journey of learning frontend technologies, strengthening core concepts, and applying them through hands-on development.

## Technologies Used

- **HTML5** – Semantic markup and web page structure
- **CSS3** – Styling, layouts, and responsive design
- **JavaScript** – DOM manipulation, ES6+ features, and interactive functionality
- **React.js** – Components, props, state management, and hooks
- **TypeScript** – Static typing, interfaces, and type-safe development
